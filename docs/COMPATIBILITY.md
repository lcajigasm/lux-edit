# Compatibility

## External Settings Import

Lux Editor can import settings from:

- VSCode-style JSON settings.
- Sublime `.sublime-settings` files.
- JetBrains XML settings files.

Current import support focuses on practical editor options, such as font size, indentation behavior, and line ending preferences.

## Editor Conventions

Lux Editor applies common project conventions from `.editorconfig` and `.gitattributes` when opening files.

## Platform

The application is built with `egui/eframe` and runs as a desktop native app via Rust.
